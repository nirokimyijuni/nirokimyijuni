| 제가 정한 것 | |
|---|---|
| 🧒 캐릭터 | Niro, Ellie, Logan (제가 직접 그렸어요!) |
| 🌈 제목 색 | 미(초록·핑크) 스(파랑·주황) 찾(빨강·노랑·하양) 기(검정·회색) |
| 🌙 밤하늘 | 남색 하늘에 별과 달 |
| 🪙 코인 | 금색 동그라미, 상자 위에 있고 주우면 다시 생겨요 |
| ☀️ 해와 달 | 하늘에서 움직여요. 시계는 24시간이에요 (아침·낮·오후·저녁·밤·새벽) |
| 🧟 좀비 | 이름은 카스테라! 체력 3, 공격력 2, 눈과 입이 빨강이에요 |
| 💀 스켈레톤 | 3단계예요. 일반은 화살, 절반은 손, 완전체는 총으로 공격해요 |
| 📦 상자 | 새 게임마다 3~10개가 랜덤으로 나와요. 몬스터는 양쪽에서 나오고, 벽이 있으면 상자 안쪽에서도 나와요 |
| 🤍 미스 | 하얀 미스를 찾으면 무기를 하나씩 줘요. 20초 뒤에 다른 곳에 또 숨어요 |
| ⚔️ 무기 | 칼, 도끼, 총이 있어요. 미스는 칼, 도끼, 총 순서로 줘요. 총이 제일 세고 귀해서 어쩌다 한 번만 나와요. 총은 상자와 구덩이 벽을 뚫지 못해요 |
| 📡 시민 | 안테나 2개 시민은 폭발하고, 안테나 1개 시민은 돌아다니며 자기 할 일을 해요 |
| 🔁 고리 맵 | 해변, 화산, 산, 집을 지나 집 오른쪽으로 가면 다시 해변이 나와요. 맵 끝이 없어요 |
| 🏆 7일 클리어 | 7일을 버티면 미스가 나와서 축하해 줘요 |
| ⭐ 점수 | 동전, 레벨업, 해치운 몬스터가 각각 1점이에요. 최고 점수도 남아요 |
| ➕ 수학 퀴즈 | 밤이 될 때와 아이템을 두 번 얻을 때 미스가 이야기 문제를 내요. 팀 친구들이 나오고, 숫자판으로 답을 넣어요. 기회는 3번이에요 |
| 🔤 영어 퀴즈 | 미스가 수학 문제와 영어 문제를 반반 내요. 그림을 보고 영어 낱말을 고르거나, 영어 낱말을 보고 그림을 골라요. 낱말은 48개, 기회는 2번이에요 |
| 🪓 캐기 | 나무와 광석을 캐요. PC는 E 키, 폰은 캐기 버튼을 눌러요. 캘 수 있는 것은 반짝여요 |
| 🌋 동굴 | 화산에 동굴이 있어요. 들어가면 철광석, 동, 은, 금을 찾을 수 있어요 |
| ⛏️ 곡괭이 | 집 제작대에서 나무 4개 + 철광석 2개로 만들어요. 제작대가 곡괭이 모양과 순서를 알려 줘요 |
| 🏠 상점 | 집에 들어가면 상점이 있어요! 코인으로 스케이트, 무지개 갑옷, 다이아몬드 갑옷, 체력 포션, 독약 포션을 사요. 금·은·동은 코인으로 팔아요. 코인은 5000개까지 모여요 |
| 💎 새 광물 | 동굴에서 다이아몬드, 에메랄드, 루비도 캐요 |
| 🚗 새 아이템 | 자동차, 주사기총, 애서열매, 다이아레어라이트 곡괭이를 제작대에서 골라서 만들어요 (그림도 제가 그렸어요!). 주사기총은 여러 개 모아서 여러 번 쏠 수 있고, 바늘은 은색이에요 |
| 📦 상자 부수기 | 도끼로 상자를 3번 치면 부서지고, 가끔 깜짝 아이템이나 몬스터가 나와요. 동굴·집 문 옆과 화산에는 상자가 없어요 |
| ⏸️ 멈춤 | Esc나 멈춤 버튼으로 잠깐 멈출 수 있어요. ↑/↓로 고르고 주황 칸으로 보여요. 멈춤 창에 친구가 랜덤으로 나와서 기다려 줘요 |
| 🎒 가방 | I 키나 가방 버튼으로 열면 가진 물건과 정보가 RPG처럼 보여요. 화면이 깔끔해졌어요 |
| ⌨️ 새 키 | Q 공격, Tab 무기 바꾸기, I 가방, 1·2 포션, R 주사기총, 3 애서열매, 문과 동굴은 ↑로 들어가요 |
| 🎯 깜짝 미션 | 미스가 낮에 하나, 밤에 하나 깜짝 미션을 알려 줘요. 성공하면 미스가 "잘했어!" 하고 코인 100개를 줘요! 실패하면 체력이 1 줄어요 |
| 💫 헤롱헤롱 | 쓰러지면 머리 위에 노란 별 5개가 빙글빙글 돌아요 |
| 🎉 끝 화면 | 끝 화면에 내가 고른 캐릭터가 나와요. 클리어하면 축하 춤을 춰요 |
| 🎬 로고 | 게임을 열면 니로 스튜디오 로고가 나와요. "눌러서 시작"을 누르면 시작해요. 폰에서는 전체화면과 가로로 바뀌어요 |
| 🌙 밤 몬스터 | 날이 갈수록 밤에 몬스터가 조금씩 더 나와요. 1일째는 그대로예요 |
| 💪 몬스터가 세져요 | 날이 지날수록 새로 나오는 몬스터의 체력이 하루에 1씩 늘어요. 1일째는 3, 7일째는 9예요. 이미 나온 몬스터는 그대로예요 |
| 🛼 스케이트 | 낮에 산 스케이트는 다음 아침까지, 밤에 산 스케이트는 두 번째 아침까지 신어요 |
| 🔎 검색 | 구글에서 찾을 수 있게 소개 글과 홈 화면 아이콘을 넣었어요 |
| ⚡ 빨리 열려요 | 그림을 한꺼번에 받아서 처음 열 때 기다리는 시간이 짧아졌어요. 폰 글씨도 덜 끊겨요 못 불러오면 "불러오지 못했어요" 안내와 다시 하기 버튼이 나와요. |
| 📱 폰에서 더 잘 열려요 | 아이폰·카톡·인스타그램에서 열면 "이렇게 하면 더 크게 볼 수 있어요" 안내가 나와요. 양옆 빈 띠도 색으로 채우고, 홈 화면에 추가해서 앱처럼 열 수 있어요 |
| 👋 첫 판 안내 | 처음 하면 Niro가 말풍선으로 걷기, 나무 캐기, 몬스터 치기를 알려 줘요. 연습용 몬스터는 쓰러뜨려도 상 받는 것이 없어요. 안 보고 싶으면 N 키나 건너뛰기 버튼을 눌러요 |
| ❓ 창 안내와 도움말 | 퀴즈·제작대·상점·가방·미션 창을 처음 열면 한 줄로 알려 줘요. 왼쪽 위 물음표(?) 버튼을 누르면 조작 안내가 한 장 나오고, 그동안 게임이 멈춰요 |
| 🔊 소리 | 음악 4곡(타이틀, 낮, 밤 동굴, 상점)과 효과음이 생겼어요! M 키나 멈춤 창의 소리 버튼으로 켜고 끌 수 있어요. 타이틀 음악은 "Children's March"로 바꾸고, 코인 소리는 새로 만들었어요. 퀴즈 정답과 레벨업 소리도 새로 바뀌었어요. |
